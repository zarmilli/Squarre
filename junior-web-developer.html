About the Opportunity

Squarredesk is looking for a motivated, detail-oriented and creative Junior Web Developer to join our growing development team. We are looking for someone with a passion for web development, an understanding of modern web technologies and an interest in building accessible, functional and visually appealing website experiences. As part of the development team, you will be responsible for creating website templates for the Squarredesk platform and ensuring that every new template meets the technical, functional and design requirements of our website editor. You'll work on developing reusable website layouts, implementing responsive designs, testing template functionality and identifying potential issues before templates are made available to users. This is an opportunity for an aspiring developer to gain practical experience within a growing technology company while contributing directly to a platform designed to make website creation and business ownership more accessible.

Job Description

As our Junior Web Developer, you will contribute to the development, testing and quality assurance of website templates within the Squarredesk ecosystem.

Your responsibilities will include:

1. Website Template Development

  • Designing and developing reusable website templates for the Squarredesk platform.
  • Building responsive website layouts that function across desktop, tablet and mobile devices.
  • Implementing website components, navigation systems, interactive elements and page sections.
  • Translating design concepts and visual references into functional website templates.
  • Ensuring templates maintain consistent styling, typography, spacing and layout structures.
  • Developing templates suitable for different industries, business categories and use cases.
  • Writing clean, structured and maintainable HTML, CSS and JavaScript.

2. Template Quality Assurance

  • Reviewing newly developed templates to ensure they meet Squarredesk's technical and design standards.
  • Testing templates within the Squarredesk website editor to verify compatibility.
  • Identifying and resolving layout inconsistencies, rendering issues and functional errors.
  • Ensuring that website elements can be edited, configured and customised through the platform's editor as intended.
  • Testing editable sections, text fields, images, buttons, navigation elements and other supported components.
  • Verifying responsive behaviour across different screen sizes and devices.
  • Checking browser compatibility and identifying potential rendering inconsistencies.
  • Documenting issues and providing feedback before templates are approved for release.

3. Editor Compatibility & Integration

  • Understanding the technical requirements and limitations of the Squarredesk website editor.
  • Ensuring that templates follow the editor's supported component structures and implementation standards.
  • Testing the behaviour of editable website elements within the editor.
  • Identifying template features that may not be supported by the platform.
  • Collaborating with the development team to resolve compatibility issues.
  • Ensuring that templates provide a consistent editing experience for end users.

4. Maintenance & Development Support

  • Updating existing templates to improve functionality, responsiveness and visual consistency.
  • Troubleshooting reported template issues and implementing necessary fixes.
  • Maintaining reusable components and development resources.
  • Following established coding standards and development practices.
  • Participating in code reviews and development discussions.
  • Keeping up with modern web development technologies, design practices and browser standards.

Role Requirements

Candidates should meet the following requirements:

  • A qualification, diploma, certificate or relevant training in Web Development, Software Development, Computer Science or a related field.
  • Basic practical experience in website development, whether through employment, freelance work, internships or personal projects.
  • Working knowledge of HTML5, CSS3 and JavaScript.
  • Understanding of responsive web design and mobile-first development principles.
  • Familiarity with website layouts, reusable components and modern web design practices.
  • Ability to identify and troubleshoot basic frontend development issues.
  • Understanding of browser compatibility and website testing.
  • Good attention to detail and an appreciation for clean, consistent design.
  • Ability to interpret design references and translate them into functional interfaces.
  • Good problem-solving and communication skills.
  • Ability to work independently and collaborate effectively in a remote development environment.
  • Access to a computer and a reliable internet connection.

Good to Have

The following skills and experience will be advantageous:

  • Familiarity with React, Vue or other JavaScript frameworks.
  • Experience working with component-based development architectures.
  • Knowledge of Git and version control workflows, particularly GitHub.
  • Familiarity with Figma and translating UI/UX designs into code.
  • Experience with website builders, CMS platforms or visual website editors.
  • Understanding of APIs and third-party integrations.
  • Basic knowledge of backend development and database structures.
  • Familiarity with performance optimisation, accessibility and SEO best practices.
  • Experience developing reusable website templates or component libraries.
  • Familiarity with modern development tools such as Vite, npm and browser developer tools.
  • A portfolio of websites, personal projects or development work demonstrating practical skills.
